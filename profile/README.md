# GonService

Software sob demanda e DevOps/SRE para empresas que precisam de sistemas confiáveis, do código ao deploy.
Custom software and DevOps/SRE services, from code to production.

[gonserviceit.com.br](https://gonserviceit.com.br) · [contato@gonserviceit.com.br](mailto:contato@gonserviceit.com.br)

## Infrastructure / Infraestrutura

| Repository | What it is |
| --- | --- |
| [github-actions-templates](https://github.com/GonService/github-actions-templates) | Reusable workflows: container build, security scan, Terraform and Helm deploys |
| [terraform-aws-static-site](https://github.com/GonService/terraform-aws-static-site) | Static site on AWS: S3, CloudFront, HTTPS, security headers and OIDC deploy role |
| [monitoring-stack](https://github.com/GonService/monitoring-stack) | Prometheus, Grafana, uptime checks and Telegram alerts in one `docker compose up` |
